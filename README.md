# Woodline — план роста e-commerce на 120 дней

Автономная интерактивная доска. Откройте `index.html` напрямую или запустите сервер:

```sh
npm start
```

Требуется Node.js 22 или новее. Зависимостей нет. Сервер слушает `0.0.0.0` и порт из `PORT` (по умолчанию 3000). Проверка работоспособности: `GET /health`.

## Railway

Создайте сервис из GitHub-репозитория `baldewrelax-eng/woodline-board`, ветка `main`. Railway использует Dockerfile и railway.json. После развёртывания включите публичный домен в Networking → Generate Domain.

## Данные

Задачи и показатели сохраняются в браузере, а не на сервере. Для переноса используйте консоль JSON. Данные локальной версии и опубликованного домена не объединяются автоматически: экспортируйте их на исходной доске и импортируйте на новом адресе. JSON может содержать рабочие данные; храните резервные копии отдельно. Общей синхронизации между сотрудниками нет.
